# 个人量化分析与交易系统 PRD（一页纸）

> 市场：A 股 ｜ 频率：日线 ~ 分钟线 ｜ 阶段：模拟盘 → 小资金实盘 ｜ 使用者：单人

## 1. 目标与范围

**做**：面向 A 股单账户的量化系统，打通「策略研究 → 回测 → 模拟盘 → 小资金实盘」的完整闭环，日线为默认频率、分钟线用于信号细化。

**不做**：
1. 高频与日内抢单（毫秒撮合、盘口套利、订单簿建模）。
2. 多券商 / 多账户接入与订单路由。
3. 期权、期货、可转债、融资融券等衍生与杠杆业务。
4. 多用户、订阅、跟单等任何对外服务形态。
5. 机构级风控中台与合规报送。

## 2. 用户与场景

单人本地使用，无登录与权限体系，配置走本地文件。

核心场景：收盘后跑日线策略回测与参数对比 → 信号进入模拟盘自动下单，与回测逐日对账，量化滑点与成交偏差 → 偏差收敛后切小资金实盘，沿用同一套信号、仓位与风控规则。

次要场景：盘中查看持仓与浮动盈亏、人工干预（撤单、手动平仓）、盘后查看当日对账表。

## 3. 功能边界

**MVP 必须有**：
1. 行情接入与本地落地（日线/分钟线，含增量更新与复权）。
2. 策略接口 + 双均线示例策略。
3. 回测引擎（手续费、滑点、涨跌停与停牌、T+1）。
4. 统一交易网关：模拟盘与实盘同一接口，单券商。
5. 基础风控：单票/总仓位上限、单日最大亏损熔断。
6. 日志与对账报表（回测/模拟/实盘三方可比）。

**明确推迟**：多策略组合、参数自动寻优、机器学习选股、分钟级实时风控、消息推送、移动端。

## 4. 验收标准

**P0 完成**指同时满足：

1. 双均线策略在近 3 年日线数据上跑通回测，输出净值曲线、最大回撤、胜率、交易明细。
2. 相同数据 + 相同参数运行两次，结果完全一致（关键指标与交易明细逐条相等）。
3. 每次回测记录数据版本、参数、代码 commit，可一键复现。
4. 模拟盘连续运行 5 个交易日，下单信号与同期回测信号一致，差异可逐条解释。
5. 进程重启或断网后能恢复状态，不产生重复下单。
